# “网”恋 v0.1.0 · 五章可玩初版

2020 年，架空城市梧城。那年城市按下暂停，你却出现在我的消息里。

- 五章完整原创故事：43 场景、507 段、六次选择、288 条路线、四种结局。
- 谢听禾与许弥原创透明立绘；旧房间、隔窗住宅、小区门口、照相馆与梧江步道五张场景。
- 横屏优先 PWA 和 Windows 安装版/便携版共用内容；底部阅读层透明度可调，支持隐藏界面。
- 自动/手动存档、JSON 导入导出、回看、自动、快进、章首重读与结局/场景/音乐归档。
- 完整离线资源、自托管中文字体；复用 Project1 六首程序配乐，Test 资产溯源与验收方法。
- 当前各角色一张基础立绘，没有角色配音、动态角色、三视图或事件 CG。

PWA 第一次联网看到“可以离线阅读”后可断网重开；手机和电脑可通过 JSON 文件迁移进度。Windows 安装包与便携 EXE 已包含全部资源。

本轮定位为可玩初版。下载资产仅在 Web 检查和实际 Windows 包启动成功后上传，SHA256SUMS.txt 对应本次安装包与 PWA ZIP。
