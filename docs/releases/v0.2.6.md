# “网”恋 v0.2.6 · 关键语音接入准备

新增离线录音播放控制器、稳定台词绑定、独立语音偏好与已读记录重听接口。语音播放期间自动阅读等待，面板和后台暂停；手动暂停保持，浏览器限制播放可经点击恢复，录音失败允许继续阅读，旧播放请求不会覆盖新段落。历史重听只在可见的回看面板中播放，关闭后停止。

本版发布清单没有录音，语音控件仅在实际存在录音时出现。v0.3.0 的十句选句已记录说话人、原文摘要与通话/无立绘属性；尚未录制、试听或加入事件 CG。五章故事、288 路线和四个结局继续作为可玩预览，当前补丁不是 v0.3.0 内容交付。

本地 57 项逻辑检查（含 288 路线）、素材校验、字体覆盖与生产构建通过；完整浏览器回归及远端双端构建以本轮实现记录和 Actions 为准。NSIS 安装/升级与 portable 封装器的实际启动仍待独立补验。
