# NetLove v1.0.0 发行实施记录

本轮将完整五章、四种结局和 220 条离线人物对白的既有内容晋级为 1.0.0 正式发行。剧情、角色可见性、录音文本、资源字节和存档身份保持；没有新增剧情、服务器或在线语音服务。基线 main 为 0a130bc704bbdd440b42313a91324df0a8628496，本轮统筹见 RELEASE-PLAN-20261022.md。

## 实施

标题页和阅读中加入“游玩帮助”，覆盖触屏 / 键盘、自动与快进、音画设置、隐藏恢复、三个手动位、完整备份迁移、临时重读、解锁、Windows 升级及 PWA 首装 / 更新。复用原生 Dialog 的焦点圈定、Esc 关闭和原入口焦点恢复，接入既有 panel 暂停条件。帮助按钮位于阅读画面左上方，避免与底部工具及重读提示重叠。短屏正文在面板内滚动，关闭按钮保持可达。

中文 Story Serif 按完整 src 文字重新子集化。官方 Google Fonts NotoSerifSC[wght].ttf 源 SHA-256 为 050080d9255a86808f2945bffac582b31ef32bc36411ce29563b4961670c66f9；运行 WOFF2 为 456ee824189be32d30afbe78cbad90dbe7f5b6093dda3ac585f742b20221ab7e，190,116 字节。OFL 许可保留，REUSABLE-ASSETS.json 更新运行摘要；共用 15 份契约文件保持原哈希。

build.yml 不再固定 --prerelease 或先公开再验证。publish-release.py 先核对本地四份附件、三项校验表、EXE 头与 PWA ZIP 完整载荷，再检查当前 main 与已有标签。已有公开版本或草稿均拒绝覆盖 / 接管；草稿使用鉴权分页列表额外查找，不把仅查询已发布版本的按标签接口当作草稿不存在的证明（[GitHub REST 文档](https://docs.github.com/en/rest/releases/releases)）。新版本只建立草稿，上传全部附件后使用鉴权下载接口逐字节核对，再次检查 main / tag，最后公开。版本带预览后缀时保留预览标记，1.0.0 使用正式标记；公开下载另以匿名 URL 回读。跨主机重定向移除 Authorization，避免签名下载地址接收到令牌。失败报告保存阶段、版本、运行提交和 releaseId，上传 / 下载 / 身份失败时保持草稿。历史 finalize-publication.yml 的 v0.2.4 流程保持不动。

Windows 安装升级验收基线从 0.2.6 更新为当前已发行的 0.5.0。源码、win-unpacked、安装升级及便携外壳仍分别实测；本地 Linux 的浏览器或构建不能代替这些 Windows 结果。
