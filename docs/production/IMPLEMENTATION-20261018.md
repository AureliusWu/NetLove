# 2026-10-18 · 关键语音接入准备

临时工作区重置后从远端 main 恢复。本提交提供真实可执行的录音生命周期和接入接口，不把上轮不可获取的文件或记录视为已发布内容。

src/game/voice.ts 独立协调录音、自动阅读、面板、页面可见性、手动暂停、浏览器手势限制和失败。代次与播放器身份隔离迟到的 play Promise，显式同段读档使用阅读会话标识触发新一次播放。回看重听使用当前可见菜单，关闭即停止。语音音量与原音乐音量分别持久化，旧设置可沿用。

src/game/voice-catalog.ts 要求稳定台词 ID、说话人与原文逐字匹配，聊天文字不自动配音。voice-manifest.json 的实际 clips 为零，未向玩家提供空的语音按钮；VOICE-BINDINGS-v0.3.0.json 单独记录十句待录制文字、文本 SHA-256 和场景属性。电话场景沿用 noSprite，不因预备录音而展示角色立绘。

本地 57 项逻辑通过，包含原 288 条路线与新增 8 项录音状态/绑定回归；TypeScript/Vite/PWA、素材和 15 份共享文件、当前中文字体覆盖通过。完整浏览器首轮 43 项通过、1 项既有结局回看用例达到 60 秒超时；该项在最终字体构建后独立重跑通过（50.7 秒），有效汇总 44 项通过。未放宽超时或减少断言。远端平台的最终结果随后追加。

后续：实际离线录音、两分支事件 CG、试听审阅、真实 NSIS 安装/升级与 portable 启动；本轮不将这些项目记为完成。
