# “网”恋 v0.1.1 · 双端可靠性修补

五章故事、两位角色、六次选择与四种结局保持原有创作；`netlove-v1` 和 `netlove:v1` 存档继续兼容。

- 离线完成状态只由本游戏自己的 Service Worker 激活证明。父目录中已经就绪的其他应用不会误报完整下载；下载失败可重试。
- 同一站点中多个路径安装同一游戏时，缓存各自隔离。构建摘要包含资源相对路径和字节，资源改名也会正确生成新缓存。
- 新版本完整下载后等待所有游戏窗口关闭，保留阅读段落与存档；子目录部署、失败恢复、双路径断网重开与更新续读纳入浏览器回归。
- Windows 安装版与便携版继续包含全部资源；源码启动和实际打包后的 EXE 分别检查。
- Rain、NetLove 与 Healing 共享制作契约 v1.1.0；可复用素材按来源、授权和 SHA-256 校验，作品独有图像保留溯源索引。
- Pages 手动发布也执行浏览器门禁，同一次工作流重试使用独立发布附件名称。

首次联网看到“可以离线阅读”后再断网。安装与离线下载分别完成，浏览器清理网站数据会删除本地存档，可先用 JSON 导出备份。

本版本继续作为可玩预览。下载资产由通过 Web 与 Windows 实际包启动门禁的 CI 发布，SHA256SUMS.txt 对应发布资产。公开部署、实际安装/升级和设备手工体验以单独记录为准。
