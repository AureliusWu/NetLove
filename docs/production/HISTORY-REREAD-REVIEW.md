# NetLove v0.2.4 · 从已读位置安全重读

2026-10-15。基线 `e59318ab57b737c095ca37451832c67e2c7833f8`，接续 v0.2.3 的已读画面预览及 v0.2.2 的完整阅读备份。

在已读记录中检索文字，查看原场景和表情后，可以选择“从这里重读”，重新作出后面的选择。右上角“返回原进度”恢复进入重读前的段落及未完成的打字位置。关闭应用或离线刷新后仍从原自动存档继续。

## 状态和写入边界

- `historyState` 仅从原生已读列表取得位置，通过 `engine.replay` 使用当时之前的选择前缀重建分数、历史和正文变体；目标处的选择尚未提交，可以重新选择。正在打字的未读段落不能成为目标。
- `liveGame` 持有原路线，临时 `reread.game` 只负责当前重读。自动存档、章首、结局、场景与音乐归档的 effect 均只依赖 `liveGame`；完成另一条结局也不写回原路线。嵌套重读继续保留最初的原路线和打字计数。
- 普通阅读备份使用原路线。重读内容只能经确认存入手动存档；取消存入、读取或导入保持原持久化数据。确认读取或导入后才退出重读、切换正式路线。
- 返回原进度停止自动/快进，恢复原打字计数；首个恢复渲染仍使用排队恢复的原计数判断正式结局是否读完，避免重读长段的字数提前触发结局归档。返回标题也结束临时重读。未改变 `netlove-v1`、`netlove:v1`、剧情 JSON、人物素材、共用检索组件和哈希锁。
- 修正 Dialog 的 Tab 首尾循环：排除实际隐藏和 inert 的控件，预览期间隐藏的搜索框不会参与焦点边界。
