# “网”恋 v0.2.5 · 后台暂停与读档续读

切换到后台时，逐字显示停在当前字数，自动与快进关闭；回到前台后继续。已经排队的打字与自动回调也直接检查页面可见性，避免后台把未读段落显示完。

手动读取或导入存档会重新显示目标段落，即使目标就是当前这一段；从标题继续同一路线时，仍保留本次阅读的未完成字数。载入首帧单独使用零字边界，避免借用上一段的字数提前解锁未读完的结局。临时重读、返回原进度、完整备份与原存档身份保持。

本地完成 49 项逻辑（288 条路线）、10 项素材工具、15 份共用文件、54 份素材文件、TypeScript/生产构建与最终 44 项浏览器检查。新增后台、迟到回调、同段读档、重读保护和未读结局首帧回归，桌面/手机各自执行。细节见 [阅读生命周期记录](../production/READING-LIFECYCLE-20261017.md)。

发行继续为可玩预览。公开版本须通过 Windows 源码与实际 win-unpacked EXE 检查、NSIS/portable 构建后发布；公开 PWA 另以部署后的字节与三屏离线验证为准。安装器安装/升级、portable 封装器启动与实体设备手工体验仍单列验收，未由本地浏览器检查替代。
